# 😂 Dad Jokes Generator — Async/Await

> A focused JavaScript project for learning asynchronous API requests with `async/await`.

## ✨ Features
- Async/await based API calls
- Automatic joke on load
- One-click new joke
- Error handling with `try/catch`
- Responsive dark UI
